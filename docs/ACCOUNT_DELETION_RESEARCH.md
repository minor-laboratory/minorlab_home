# 계정 삭제 페이지 구현 리서치 문서

> 작성일: 2025-09-18
> 목적: 구글 플레이 스토어 계정 삭제 정책 준수를 위한 분석 및 개선방안

## 🎯 구글 플레이 스토어 요구사항 (2025)

### 필수 요구사항
1. **웹 링크 제공**: 앱을 재설치하지 않고 계정 삭제 요청 가능
2. **앱/개발자 이름 명시**: 스토어 등록정보와 일치하는 이름 표시
3. **명확한 삭제 단계**: 사용자가 취해야 할 단계를 눈에 띄게 표시
4. **삭제 데이터 유형 명시**: 어떤 데이터가 삭제/보관되는지 구체적 설명
5. **데이터 보관 기간**: 법적 요구사항에 따른 보관 기간 명시

### 기능적 요구사항
- 링크가 정상 작동해야 함 (로딩 에러 없음)
- 계정 삭제 경로가 쉽게 발견 가능해야 함
- 앱 이름이나 개발자 이름을 참조해야 함

## 🔍 상용 서비스 사례 연구

### Netflix
- **삭제 방법**: 웹사이트를 통한 계정 해지
- **데이터 처리**: 10개월 후 완전 삭제, 법적 요구사항 예외
- **사용자 안내**: 구체적인 삭제 일정과 데이터 유형 명시

### Spotify
- **삭제 방법**: 앱 내 + 웹사이트 양방향 제공
- **데이터 처리**: 즉시 삭제 + 30일 복구 기간
- **투명성**: 각 데이터 카테고리별 처리 방식 상세 설명

### Instagram (Meta)
- **삭제 방법**: 앱 내 + 웹 인터페이스
- **데이터 처리**: 30일 유예 기간 + 90일 완전 삭제
- **서드파티**: 연동된 서비스들의 데이터 처리 방식 별도 안내

### 공통 패턴
1. **즉시 접근 불가 + 지연 삭제**: 계정 비활성화 → 유예기간 → 완전삭제
2. **데이터 분류**: 프로필 정보, 콘텐츠, 활동 기록 등 카테고리별 처리
3. **법적 예외**: 부정행위 방지, 법적 요구사항 등으로 인한 보관 데이터 명시
4. **서드파티 안내**: 연동된 외부 서비스의 데이터 처리 별도 설명

## 📊 현재 구현 분석

### ✅ 충족하는 요구사항
- 웹 링크 제공 (https://minorlab.com/account-deletion/)
- 앱 이름(BookLab) 및 개발자 이름(MinorLab) 명시
- 명확한 2가지 삭제 방법 제시 (앱 내 + 이메일 요청)
- 단계별 처리 절차 안내
- 이메일 확인을 통한 보안 검증

### ❌ 누락된 요구사항

#### 1. 삭제 데이터 유형 상세화 부족
**현재**: "모든 데이터(독서 기록, 메모, 목표 등)"
**필요**:
- 개인 정보 (이메일, 프로필 정보)
- 독서 기록 데이터 (읽은 책, 진행률, 완독일)
- 사용자 생성 콘텐츠 (메모, 리뷰, 목표)
- 앱 사용 분석 데이터
- 기기 및 로그 정보

#### 2. 데이터 보관 기간 정보 누락
**현재**: 처리 기간만 명시 (3일 내 확인 이메일)
**필요**:
- 즉시 삭제되는 데이터 vs 유예 기간이 있는 데이터
- 법적 보관 의무가 있는 데이터 (결제 기록, 부정행위 방지 등)
- 완전 삭제까지의 전체 일정

#### 3. 서드파티 서비스 데이터 처리 정보 부족
**현재**: MinorLab 자체 데이터만 언급
**필요**:
- Google/Apple 로그인 연동 데이터
- Firebase Analytics 데이터
- Supabase 백엔드 데이터
- RevenueCat 결제 데이터
- 각 서비스별 데이터 삭제 정책 및 처리 방식

#### 4. 사전 필수 조치 안내 부족
**현재**: 바로 삭제 가능한 것으로 안내
**필요**:
- 활성 구독 취소 필요 여부
- 미완료 결제나 환불 처리
- 다른 기기에서의 로그아웃 필요성
